## Overview

Audio Damage Other Desert Cities is a multi-tap delay with analog-inspired character, offering four independent delay taps with per-tap filtering, panning, and feedback control.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Audio Damage Other Desert Cities** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Four Taps** | Independent delay time, level, pan, and filter per tap |
| **Analog Character** | Tape saturation and wow/flutter emulation for warmth |
| **Sync Mode** | BPM-synced delay times with musical note divisions |
| **Modulation** | LFO-driven pitch and time modulation for chorus-like effects |
